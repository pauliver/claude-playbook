# Plans

`NNN-kebab-title.md`. Never overwrite a plan: mark it `superseded` and link the new one. Header:

```
**Status:** draft | approved | in-progress | done | superseded (by NNN)
**Date:** YYYY-MM-DD   **Owner:** <who>   **Tracking issue:** #N
**Goal:** <one line>
```

A multi-phase plan gets ONE tracking issue (plan = working copy; issue = tracked copy). Cite plans by filename —
numbers collide when plans merge.
